# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0-MVP] - 2026-07-12
### Added
- Complete transition from telemetry-tracker to "Social Journey Platform".
- JSON Theme Engine with initial templates.
- Multi-format (9:16, 4:5, 16:9) ViewShot rendering.
- New database schema for `collections`, `journey_interactions`, and `drive_media`.
- `ExploreScreen` with algorithmic Discovery Engine.
- `JourneyDetailScreen` for long-form storytelling.
- Organic Growth watermark ("Created with DRIVE").
- Complete GitHub startup-grade repository organization.

### Removed
- Unused hardcoded UI templates.
- Explicit raw telemetry presentation from user-facing screens (kept in background).
